## Этап 2 — Frontend

**Цель:** покупатель может пройти весь путь на сайте: найти мебель, посмотреть её в 3D, выбрать вариант, оформить заказ.

- [x] apps/web на Next.js, подключение @luxiwood/shared (shadcn/ui, Lucide, Motion, React Three Fiber)
- [x] Главная страница
- [x] Вход, регистрация, восстановление пароля (ФТ-20, ФТ-22)
- [x] Каталог с подбором (тип, цвет, ширина, бюджет, комната, срок, подборки), сортировка, поиск
- [x] Личный кабинет: заказы, избранное, профиль, смена пароля через Gmail
- [x] Корзина и оформление заказа (товары каталога)
- [ ] Каталог: категории, поиск, фильтр по цене, сортировка, страницы (ФТ-01, ФТ-02)
- [ ] Страница товара: фото, описание, характеристики (ФТ-03)
- [ ] 3D-просмотр на React Three Fiber: .glb или встроенная модель, смена цвета (ФТ-04)
- [ ] Выбор ткани, дерева, размера; мгновенная цена через shared + проверка через API (ФТ-05, ФТ-06)
- [x] Конструктор мебели с 3D-превью (ФТ-07)
- [ ] Корзина в браузере (ФТ-08)
- [ ] Оформление заказа с проверкой телефона (ФТ-09)
- [ ] Страница отслеживания заказа (ФТ-10)
- [ ] Адаптивная вёрстка от 360 px (НФТ-04)

**Этап завершён, когда:** на телефоне и компьютере можно от главной страницы дойти до оформленного заказа и увидеть его статус; цена на сайте совпадает с ценой в заказе.

**Цель:** администратор мастерской сам ведёт каталог и заказы через интерфейс, без программиста. (API уже готов на этапе 1.)

- [x] Страница входа, хранение токена, выход
- [x] Категории: список, создание, изменение, порядок (ФТ-12)
- [x] Товары: список, форма товара, привязка материалов и размеров (ФТ-13)
- [x] Материалы: ткани, дерево, отделки с выбором цвета (ФТ-14)
- [x] Загрузка фото и .glb с предпросмотром (ФТ-15)
- [x] Заказы: список с фильтром, карточка, смена статуса (ФТ-16)
- [x] Цены конструктора (ФТ-17)
- [x] Обзор продаж, клиенты, модерация отзывов (ФТ-26 — ФТ-28)
- [x] Администраторы: добавление, изменение имени, email и пароля, удаление

**Этап завершён, когда:** администратор может добавить новый товар с фото и 3D-моделью, поменять цены конструктора и провести заказ от `NEW` до `DONE` только через админку.
