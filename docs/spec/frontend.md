# Фронтенд (apps/web, Next.js)

> **Статус:** сделаны вход, регистрация, восстановление пароля, главная, каталог, корзина с оформлением заказа и личный кабинет. Остальные страницы из таблицы ниже — план (этап 2 в [ROADMAP.md](../ROADMAP.md)).
>
> **Дизайн:** холст Luxiwood в Claude Design. Стиль «чертёж мастерской»: тёмно-синий фон с сеткой, медный акцент, голубые линии чертежа, шрифты Unbounded (заголовки), Onest (текст), JetBrains Mono (размеры, подписи).

## 1. Стек

| Что | Технология |
|---|---|
| Фреймворк | Next.js 16 (App Router, Cache Components), TypeScript strict |
| Стили и компоненты | Tailwind CSS 4, shadcn/ui (стиль base-nova на Base UI), иконки Lucide |
| Анимации | Motion (`motion/react`): появление блоков при прокрутке, переходы форм, мобильное меню |
| 3D | three.js + React Three Fiber + drei: вращение, плавная смена цвета; `.glb` — план |
| Уведомления | sonner (через shadcn) |
| Общий код | `@luxiwood/shared`: типы ответов, перечисления с русскими названиями, формулы цены и конструктора, правила этапов, проверка телефона |
| Запросы | `fetch` через одну обёртку `lib/api.ts` |

**Next.js 16 отличается от прежних версий** — перед работой читайте `apps/web/node_modules/next/dist/docs/`. Главное: данные из API без `"use cache"` загружаются при каждом запросе, и компонент с таким запросом должен быть внутри `<Suspense>`.

Библиотеки для серверных данных и форм (TanStack Query, react-hook-form) добавляются, только если без них код станет сложнее.

## 2. Страницы

| Адрес | Экран на холсте | Что на нём | Эндпоинты |
|---|---|---|---|
| `/` | Главная | хиты, новинки, скидки, категории, комнаты, доставка | `/products?badge=…`, `/products?sale=true`, `/categories`, `/settings/public` |
| `/catalog` | Каталог — подбор | фильтры, сортировка, страницы; фильтры живут в адресе (`?room=LIVING&maxWidth=230`) | `/products`, `/products/filters`, `/categories` |
| `/product/[slug]` | Страница товара (3D) | фото, 3D, выбор ткани, цвета, дерева, размера, количество, цена с расшифровкой, «Встанет ли у вас?», отзывы, избранное | `/products/:slug`, `/pricing/quote`, `/pricing/fit`, `/products/:id/reviews` |
| `/constructor` | Конструктор мебели | тип, размеры ползунками, материалы, опции, 3D-превью, цена и срок | `/configurator/options`, `/configurator/quote` |
| `/cart` | Корзина и оформление | позиции, количество, доставка, форма заказа, номер заказа после оформления | `/orders`, `/settings/public`, `/auth/me` (подставить имя, телефон, адрес) |
| `/track` | — | отслеживание по номеру и телефону | `/orders/track` |
| `/login`, `/register`, `/forgot-password` | Вход и регистрация | вход по имени или email, регистрация, сброс пароля кодом | `/auth/*` |
| `/account` | Личный кабинет | мои заказы с этапами и отменой, избранное, профиль, смена пароля | `/me/*`, `/auth/me`, `/auth/password` |
| `/admin/*` | Админка | обзор, заказы, товары, материалы, категории, клиенты, отзывы, настройки | `/admin/*` |

`/account` — только со входом, `/admin` — только `ADMIN`; остальным — переход на `/login`.

**Главная** повторяет холст: шапка с нумерованным меню, первый экран «Лист 01» с GLB-диваном (обивка из 5 тканей, вращение мышью, размерные линии и штамп чертежа), полоса цифр, сборка дивана по 6 шагам при прокрутке (секция 560vh), блок конструктора, коллекция — по одному товару каждого типа из `/products` с 3D-превью и избранным, цитата, «Как заказать», подвал. Товары и контакты в подвале — из API внутри `<Suspense>`.

**Каталог** повторяет холст: заголовок «Лист 02» с поиском, «колода» подбора — тип мебели с 3D-превью, веер образцов цвета и дерева, «впишется в нишу» (ползунок ширины с точками моделей), бюджет (гистограмма цен и два ползунка), комната, срок, подборки; плашки выбранных фильтров, сортировка, карточки с размерной линией. Все товары (до 100) грузятся одним запросом и фильтруются в браузере; только для цвета спрашиваем `/products?color=ID` — в списке товаров цветов нет. С адреса читаются `?room=` и `?type=`.

**Корзина** — позиции с 3D-превью, количество, удаление; справа итог (доставка бесплатна от `freeDeliveryFrom` из `/settings/public`) и форма заказа: имя, телефон (проверка `isValidPhone`), адрес, дата доставки на 14 дней вперёд, оплата, комментарий. Со входом поля заполняются из профиля, заказ привязывается к аккаунту. После `POST /orders` корзина очищается и показывается номер заказа. В корзину попадают и товары каталога, и мебель из конструктора.

**Личный кабинет** — вкладки «Мои заказы» (этапы, отмена на этапе «Принят»), «Избранное», «Профиль»: имя, почта, телефон, адрес (`PATCH /auth/me`) и смена пароля через Gmail — код из 6 цифр приходит на почту из профиля, затем `POST /auth/reset-password`, токен заменяется новым.

**3D-модели** лежат в `apps/web/public/models/*.glb` (сжаты meshopt): диван «Glam Velvet Sofa» © 2021 Wayfair (CC BY 4.0 — указание авторства в подвале обязательно), кресло «Sheen Chair» © 2020 Wayfair (CC0), кровать «Gothic Bed 01» Poly Haven (CC0), стол pmndrs market (CC0). Шкаф (`buildWardrobe` в models.ts) и шесть видов без GLB — стул, комод, тумба, стеллаж, пуф, скамья (`viewer3d/procedural.ts`) — собираются из блоков в коде. Логотип — `public/logo.png`.

## 4. Правила

1. **Цена:** при выборе вариантов цена показывается сразу через `calcProductPrice` / `calcConfiguratorPrice` из `shared`, затем уточняется запросом `/pricing/quote` или `/configurator/quote`. В заказ уходит только выбор (ID и размеры), не цена — сервер считает сам.
2. **Корзина** хранится в `localStorage`, сервер её не хранит. Позиция — то же, что элемент `items` в `POST /orders` (товар с ID вариантов или мебель из конструктора), плюс подпись и картинка для показа. После успешного заказа корзина очищается.
3. **Токен** — в `localStorage`, `lib/api.ts` подставляет `Authorization: Bearer`. На 401 токен удаляется, пользователь идёт на `/login`. После смены или сброса пароля токен заменяется новым из ответа.
4. **Ошибки:** показываем `message` из ответа API, а `errors` — под полями формы. Тексты уже на русском, переводить не нужно.
5. **3D:** `modelUrl`, если есть, иначе встроенная модель по `model3dKey`; цвет частей — `hex` выбранных материалов. Модель грузится лениво (только на странице товара и в конструкторе), управляется пальцами. См. [media.md](./media.md).
6. **Телефон** проверяется до отправки тем же `isValidPhone` из `shared`, пример формата — `+992 90 123 45 67`.
7. **Этапы заказа** показываются названиями из `ORDER_STATUS_LABELS`; в админке доступны только кнопки, для которых `orderStatusChangeError` возвращает `null`.
8. **Тексты интерфейса** не пишутся прямо в компонентах, а берутся из `texts/ru.ts`: позже добавится таджикский.
9. **Работа на телефоне:** от 360 px; фильтры каталога — в выезжающей панели, таблицы админки прокручиваются в своём блоке.
10. **Запуск** остаётся прежним: `pnpm dev` из корня запускает и API, и сайт.

## 5. Переменные окружения

`apps/web/.env.local`:
```
NEXT_PUBLIC_API_URL=http://localhost:4000   # запросы идут на ${API_URL}/api, файлы — ${API_URL}/uploads/...
```

API разрешает запросы только с адреса из `CORS_ORIGIN` (по умолчанию `http://localhost:3000`).
