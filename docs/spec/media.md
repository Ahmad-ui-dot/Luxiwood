# Фото и 3D-модели

Код: `apps/api/src/uploads/uploads.controller.ts`. Эндпоинты — раздел «Админ: загрузки» в [api.md](./api.md).

## 1. Схема загрузки: через API на диск

```
1. Админка: POST /api/admin/uploads/image  (multipart/form-data, поле file)
            → { url: "/uploads/images/3f2c9a1b7d4e5f60.jpg", size, originalName }
2. Админка: PATCH /api/admin/products/:id { images: [...старые, url] }
            (для модели — POST /api/admin/uploads/model → PATCH { modelUrl: url })
3. Сайт:    <img src={API_URL + url}>, модель грузится по API_URL + modelUrl
```

Файлы сохраняются в `apps/api/uploads/images/` и `apps/api/uploads/models/` под случайным именем (16 hex-символов + расширение в нижнем регистре) и раздаются как статика по `/uploads/...` — без префикса `/api` и без входа.

**Почему на диск, а не в облако:** каталог небольшой, файлы загружает только администратор, внешний сервис и ключи не нужны. Для деплоя на сервер без постоянного диска это придётся поменять (см. [architecture.md](./architecture.md), «Что сознательно НЕ используем»).

## 2. Типы и ограничения

| Что | Путь | Расширения | Лимит |
|---|---|---|---|
| Фото товара | `/uploads/images/` | `.jpg`, `.jpeg`, `.png`, `.webp` | 5 МБ |
| 3D-модель | `/uploads/models/` | `.glb` | 30 МБ (рекомендуется до 5 МБ, чтобы быстро открывалась на телефоне) |

- Другой тип → 400 «Можно загрузить только фото jpg, png или webp» / «…только 3D-модель в формате .glb».
- Больше лимита → 413 «Файл слишком большой: фото — до 5 МБ, 3D-модель — до 30 МБ».
- Без файла → 400 «Прикрепите файл в поле file».
- Один файл за запрос.

## 3. Удаление

`DELETE /api/admin/uploads?url=/uploads/images/<имя>.jpg` удаляет файл с диска. Принимаются только ссылки нашего вида (`/uploads/(images|models)/<hex>.<расширение>`), поэтому выйти за пределы папки нельзя. Ссылку из товара (`images`, `modelUrl`) нужно убрать отдельно через `PATCH` товара — API сам не отслеживает, где используется файл.

## 4. 3D на сайте (план)

- Если у товара есть `modelUrl` — показывается эта модель `.glb`.
- Если нет — встроенная модель по `model3dKey` (`sofa`, `armchair`, `bed`, `wardrobe`, `table`).
- Цвет модели меняется по `hex` выбранного материала: ткань или цвет обивки — на мягкие части, дерево — на ножки и корпус.
- Модель вращается и приближается мышью и пальцами.

Подробнее — [frontend.md](./frontend.md).

## 5. Git

Загруженные файлы в git не попадают: в `.gitignore` стоит `apps/api/uploads/**/*`, оставлены только пустые папки `images/` и `models/` с `.gitkeep`.
